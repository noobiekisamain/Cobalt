# Cobalt Execution Framework

Cobalt is a powerful, high-performance execution framework built for stability, safety, and speed.

---

## ⚡ Key Features

* **99% sUNC Compatibility:** Supports nearly all standard Universal Naming Convention (UNC) functions for maximum script compatibility.
* **Level 8 Execution Context:** High-privilege thread identity ensuring full access to core engine operations and advanced script structures.
* **Windows Dedicated:** Built specifically for Windows platforms to ensure optimal performance and minimal latency.

## 🛡️ Antivirus Notice (False Positives)

Because Cobalt interacts closely with process memory to achieve Level 8 execution privileges, Windows Defender or third-party antivirus software may flag the executable as a false positive. 

* **Solution:** If the download gets blocked or the `.exe` fails to launch, add `Cobalt.exe` or its installation directory to your antivirus exclusions list.
